# Independent / external scientific validation

Module: `backend/app/external_validation.py` · API: `/api/external-validation/*` · UI: **External Validation**

Software tests (pytest, Vitest, Playwright) prove behaviour. They are not scientific evidence. This page lists only
comparisons against reference data, each with an independence assessment.

## Reference sources

| Source | Validates | Independence | Status |
|---|---|---|---|
| Withheld real Suomi NPP VIIRS (chronological hold-out) | harmonization | independent of the model fit (never seen in training); same sensor family as the target by design | AVAILABLE — results below |
| State forest / fire service / disaster authority incident registers | fire events | independent ground reports (exclude records logged from FIRMS alerts) | BLOCKED BY EXTERNAL DATA — no public bulk feed; authorised CSV import ready |
| MCD64A1 C6.1 burned area | events / burned area | **not independent** of MODIS active fires (guides the burn mapping) — corroboration only | BLOCKED BY CREDENTIALS (LAADS licence) |
| VNP64A1 v002 burned area | events / burned area | **not independent** of VIIRS active fires — corroboration only | BLOCKED BY CREDENTIALS |
| INSAT-3D/3DR fire (MOSDAC) | events / diurnal | independent sensor and algorithm; coarse pixels make non-detection weak evidence | BLOCKED BY DATA ACCESS |
| CPCB CAAQMS / OpenAQ PM2.5 | smoke | independent in-situ (many non-fire PM sources) | BLOCKED BY CREDENTIALS |

## Harmonization vs baselines (authentic, computed 2026-11-15)

Chronological hold-out: calibration trained on 2017+ overlap years; scored on 59 real S-NPP VIIRS months
(Feb 2012 – Dec 2016) the model never saw. National monthly totals.

| Model | WAPE % | Bias % | RMSE | MAE | r |
|---|---|---|---|---|---|
| Raw MODIS (Terra + Aqua counts) | 85.1 | −85.1 | 53,848 | 36,327 | 0.96 |
| Naive MODIS + VIIRS sum | 14.9 | **+14.9** | 9,122 | 6,372 | 1.00 |
| Single constant VIIRS/Aqua ratio | 32.0 | +1.4 | 20,569 | 13,655 | 0.90 |
| **PyroScope harmonized** | **13.0** | **−0.3** | 9,241 | 5,559 | 0.98 |

90 % band empirical coverage on the held-out months: 93.2 %. The naive sum contains the target itself, so its error is
pure double counting (+14.9 % bias — the MODIS share): adding sensor counts is wrong even when it looks close.

Per-state table (`/api/external-validation/harmonization-states`): chronological hold-out with the **national**
calibration — this measures regional transfer under a temporal hold-out. A true leave-region-out **refit** (spatial
hold-out) is **not implemented** (PARTIAL). The 2012 seam verdict remains **PARTIAL** (recomputed 2026-11-15).

## Fire events vs incidents

`POST /api/external-validation/incidents` (admin): CSV with `incident_id, source_authority, start_date, latitude,
longitude` (+ optional `end_date, state, district, area_ha, incident_type, notes`), plus mandatory dataset name and
licence. Records are never generated by PyroScope. Matching (`/api/external-validation/results`): an incident matches an
event whose box is within 5 km and whose detection window overlaps the incident ±2 days. Reported: recall, missed-incident
rate, precision and F1 as **lower bounds** (registers are incomplete), median distance and start-time error.
No register is loaded → **BLOCKED BY EXTERNAL DATA**.

## Burned area, smoke, forecast

Burned-area corroboration: `/api/burned-area/events` (not independent). Smoke/PM2.5: blocked (no ground data, no
dispersion model). Forecast skill (Brier, ROC-AUC, PR-AUC, reliability, precision/recall) stays in the existing
forecast evaluation (MODEL_COMPARISON.md); it is chronological, not independent of FIRMS.

## Hold-out design

Chronological splits only (no random splits); morning-gap uses 20-month Aqua-withheld blocks with whole years removed
from training; no temporal leakage. Spatial leave-region-out refit: not implemented.
