## D. Running

```bash
cd backend && python -m pip install -r requirements.txt
python -m app.migrate                         # database setup / upgrade (backs up SQLite)
python -m app.pipeline --recover-lfs          # data pipeline (add --only-new for incremental)
uvicorn app.main:app --port 8000              # API
cd ../frontend && npm ci && npm run dev       # UI on :5173
cd ../backend && python -m pytest tests -v    # backend tests
cd ../frontend && npm run build               # production build
python -m app.science_report                  # regenerate docs/SCIENTIFIC_VALIDATION.md (from backend/)
```
